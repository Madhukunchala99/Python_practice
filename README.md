# Python, APIs and AI Model Practice

## About This Repository

This repository contains my hands-on practice in Python programming, Python libraries, JSON data handling, API integration, and AI model experimentation as part of my learning journey in AI. I have practiced using libraries such as Pandas and NumPy for data handling and numerical operations, worked with JSON to structure and process data, explored how APIs send and receive information between applications, and experimented with AI models such as Llama to understand how large language models process prompts and generate responses. This repository brings together my practice exercises, experiments, and learnings while building a foundation in Python and practical AI applications.
